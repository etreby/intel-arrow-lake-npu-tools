# Code of Conduct

We want a welcoming, technically rigorous community. Participants must be respectful, constructive, and considerate regardless of experience, identity, background, or hardware choice.

Harassment, discrimination, personal attacks, threats, doxxing, and intentionally unsafe technical advice are not acceptable. Debate ideas using reproducible evidence and acknowledge uncertainty on untested hardware.

Maintainers may edit or remove inappropriate contributions and restrict participation when needed. Report conduct concerns privately to the repository owner through their GitHub profile. Reports will be reviewed fairly and confidentially.
